# 叙事短片格式指南（5-10分钟）

5-10分钟是默认体量。若 `SKILL.md` 已将明确的单篇叙事作为缩放例外路由到本方法，按作品定义中的真实目标时长等比调整结构与场景预算；仍使用完整八步，不产生第五条路线。

## 核心特征

- **时长**：5-10分钟
- **角色**：1-2个主角，有完整的Want/Need/Arc
- **结构**：四段式（起因→发展→高潮→结局），聚焦单一核心事件
- **弧光**：一次完整的A→B变化
- **世界观**：简洁明了，30秒内观众理解规则
- **节奏**：信息密度高，每个场景都必须推进情节或揭示性格

## 短片的核心约束

短片只允许一个"单一核心事件"，不能有支线、不能分散焦点。
所有的场景都服务于同一个戏剧动作——主角追求目标、遭遇阻碍、做出选择。

除非用户特别要求，所有设定都应发生在现实主义背景之下，禁止过于夸张或过于戏剧性的设计。

## 完整八步工作流

### 第一步：破题与核心动作

**目标：** 确立短片的"核"。
**输入请求：** 如果用户已有构思，直接使用。如果用户没有明确想法，用 core-methodology.md 第九节的选题工具库通过自然对话引导（不要展示路径菜单）。

**执行逻辑：**
1. 基于用户输入，构思3-5个核心戏剧动作
2. 戏剧动作 = 目标 (Goal) + 阻碍 (Conflict)，必须是"有目的的追求"
3. 确保事件聚焦，适合短片体量

**输出格式（严格按此输出，不添加场景等未提及内容）：**

* **方案 A/B/C：**
  * 主角：
  * 目标 (Want)：
  * 阻碍 (Conflict)：
  * 一句话故事梗概 (Logline)：

> 此步完成后，使用 `SKILL.md` 的统一中间步骤审批菜单并停止。

**内部检查：核心概念与戏剧动作**
- [ ] 戏剧动作有效性：是否建立了"目标+冲突"？
- [ ] 目标有效性：目标是否合理且急切？是否和阻碍有强烈关系？
- [ ] 冲突构建：是否存在明确的内/外部冲突？阻碍是否在合理尺度内？目标和阻碍的冲突是否是驱动故事的发动机？

---

### 第二步：梗概草稿

**目标：** 让用户对整体故事的走向和气质有基本判断，再往下深入。

**执行逻辑：**
1. 基于用户选定的方案，写一段话（100-200字）的故事提要
2. 提要应包含：主角是谁、处于什么处境、因为什么事件被逼入什么困境、最终走向什么结局（可以模糊）
3. 提要的语气应该暗示全片的气质——是沉重还是轻快、是温暖还是冷冽

**输出格式：**

```
【梗概草稿】
（一段话的故事提要）
```

这个梗概在后续步骤中可以继续调整。

> 此步完成后，使用 `SKILL.md` 的统一中间步骤审批菜单并停止。

**内部检查**
- [ ] 梗概是否传达了故事的核心冲突？
- [ ] 读完梗概后，是否对"这是一个什么样的故事"有清晰感受？
- [ ] 梗概的语气是否暗示了全片的气质？

---

### 第三步：人物深度与弧光

**目标：** 拒绝纸片人，建立人物内在张力。

**执行逻辑：**
1. 设计人物外在需求 (Want) vs 内在欲望 (Need)
2. 设计人物小传——挖掘前史作为冲突根源
3. 设计人物矛盾性——外在表现 vs 内在真实
4. 除非用户特别要求，禁止过于夸张的设计

**输出格式：**
* **人物：** [姓名]
* **外在需求：** [驱动动作的目标]
* **内在欲望：** [角色未意识到的灵魂缺口]
* **人物弧光：** [从A状态 → B状态]
* **人物小传关键点：** [关键前史]
* **矛盾特征：** [外在 vs 内在]

> 此步完成后，使用 `SKILL.md` 的统一中间步骤审批菜单并停止。

**内部检查：人物塑造与弧光**
- [ ] 外在需求和内在欲望是否清晰且对立？
- [ ] 是否预设了不可逆的内在变化？
- [ ] 结局是否展示了"新常态"？
- [ ] 是否具备矛盾性？行为是否符合小传逻辑？

---

### 第四步：前史与世界观

**目标：** 遵循"电影是现实生活的横截面"——故事开始之前，世界已经存在了。

短片不需要像长片那样完整建造世界观，但需要明确以下信息（编剧自己必须知道，不一定全部展示给观众）：

**输出格式：**
* **时代/环境背景：** [故事发生在什么时代、什么环境、什么社会氛围下]
* **角色前史关键事件：** [在故事开始之前，主角经历过什么导致了当前的处境和性格]
* **关系既往：** [如有重要关系，这段关系在故事开始之前是什么状态]
* **故事从哪个横截面切入：** [为什么选择从这个时刻开始讲——这个时刻有什么特殊性]

**注意：** 前史信息在剧本中通过对白和视觉线索自然散落，不要集中闪回或旁白交代。如非必要不用闪回。

> 此步完成后，使用 `SKILL.md` 的统一中间步骤审批菜单并停止。

---

### 第五步：结构大纲

**目标：** 搭建短片骨架，确保节奏递进。

**执行逻辑：**
1. 使用四段式结构
2. 只有一个单一核心事件，避免支线
3. 第四步中的重要前史细节需在第一幕和第二幕中自然展示（如非必要不用闪回）
4. 必须包含激励事件和"一切尽失"时刻
5. **开场的前15秒必须有视觉钩子**——第一个画面就应该包含信息或悬念，最有效的是一个"不太对"的日常画面

**输出格式：**

* **第一幕：起因**
  * 开场钩子（前15秒的画面/动作）：
  * 建置（故事常态展现）：
  * 激励事件（打破平衡）：

* **第二幕：发展**
  * 冲突升级（障碍1）：
  * 冲突进一步升级（障碍2，不可省略）：
  * 中点（伪胜利/伪失败）和一切尽失：

* **第三幕：高潮**
  * 最终对决（动作顶点）：
  * 关键选择和故事反转：

* **第四幕：结局**
  * 新常态（弧光完成）：

> 此步完成后，使用 `SKILL.md` 的统一中间步骤审批菜单并停止。

**内部检查：结构与节奏**
- [ ] 开场钩子是否在前15秒内就抓住观众？
- [ ] 四个部分是否清晰？
- [ ] 激励事件、高潮是否明确？
- [ ] 每一部分是否都在推动情节或揭示性格？
- [ ] 是否去除了无效情节？
- [ ] 障碍2是否存在且与障碍1不同质？
- [ ] 各部分的时长预算是否合理？（建置约15%，发展约40%，高潮约25%，结局约20%）

---

### 第六步：场景拆解

**目标：** 将大纲转化为具体的视听单元。

**执行逻辑：**
1. 将第五步中每个情节点拆解为一个或几个核心戏剧动作（目标 → 障碍 → 结果）
2. 确保每个大的戏剧动作可拆解为几个微型戏剧动作
3. 每场戏标注预估时长和双轨节奏状态

**输出格式：**
* **第1场戏：** ...（约X秒）情节：松/中/紧 | 情感：轻/中/重
* **第2场戏：** ...（约X秒）情节：松/中/紧 | 情感：轻/中/重
* **...**
* **时长累计：** X分X秒 / 目标总时长X分钟

> 此步完成后，使用 `SKILL.md` 的统一中间步骤审批菜单并停止。

**内部检查**
- [ ] 第五步中每个情节点是否都有具体拆分？
- [ ] 场景连接是否紧凑？
- [ ] 相邻场景之间是否有情节过渡？
- [ ] 场景时长累加是否与目标总时长吻合？
- [ ] 是否有连续3场以上同一节奏状态？（如有则需要调整）
- [ ] 情节节奏和情感节奏是否有至少一处错位？（更高级的叙事）

**第六步完成后，如果短片总时长超过8分钟或场景超过8场，建议触发一次记忆检查点**（见 core-methodology.md 第十节），记录角色状态和活跃线索后再进入写作。

---

### 第七步：场景写作

**目标：** 填充血肉，执行视觉写作和潜台词。
**输入请求：** 请用户指定要生成的场景编号（或全部）。

**执行要求：**
1. **视觉写作**：严禁心理描写，只写能被看见的动作和能被听见的声音
2. **潜台词**：对话像冰山，避免直白。利用动作、停顿、回避表达真意
3. 标准剧本格式输出

如第七步按指定场景分批交付，每批结束时标明已完成场景和剩余场景，并使用 `SKILL.md` 的统一中间步骤审批菜单；该步未全部完成时，用户 `[通过]` 后继续下一批，不进入剧本医生。

> 此步完成后，使用 `SKILL.md` 的统一中间步骤审批菜单并停止。

**内部检查：场景写作与视听语言**
- [ ] 是否有心理描写？（如有则Fail）
- [ ] 是否用画面叙事？
- [ ] 对话是否过于直白？
- [ ] 是否利用了潜台词和肢体语言？
- [ ] 台词是否口语化？

---

### 第八步：剧本医生

**目标：** 按用户指定范围诊断与优化；用户要求改写时，交付可直接替换的改写稿。

**执行逻辑：**
1. 先锁定用户本轮范围：全片诊断，或对白、结构、场景等定向任务；不回滚范围外已通过的决定
2. 在所需上下文内通读剧本，寻找与本轮范围直接相关的逻辑漏洞、节奏拖沓、直白对话或角色声音趋同
3. 用户只要诊断时给出问题与修改依据；用户要求改写时，必须同时交付可直接替换的改写稿，不停在建议层
4. 全片诊断时检查各场景的时长预算——是否有场景比预计长/短太多？对整体节奏的影响？
5. 用户需要探索时，再提供 What-If 多版本方向

**输出格式：**

* **诊断报告（只保留用户本轮范围内的适用项）：**
  * 节奏问题：（含双轨节奏诊断——情节和情感的起伏是否合理？）
  * 时长问题：（哪些场景过长/过短？高潮段时长是否足够？）
  * 逻辑漏洞：
  * 对话问题：

* **优化建议：**
  * [建议1：针对某场景的潜台词重写]
  * [建议2：针对结局的反套路构思]

* **定向改写稿（用户要求改写时必交）：**
  * 按场景标出可直接替换的对白、旁白或段落
  * 保留角色意图、剧情事实和范围外已通过内容
  * 对白改写需让角色声音可区分；必要的停顿、动作或表演提示与台词措辞分开标注

**综合内部检查**
全片诊断才按核心概念、人物、结构、视听四大板块给出最终评语；定向任务只检查本轮范围及其必要上下文，不扩写成全片诊断。

> 此步完成后，使用 `SKILL.md` 的统一最终审批菜单并停止。

## 短片节奏技法

### 前史展示
前史信息通过对白和视觉线索自然散落，不要集中闪回或旁白交代。

### 节奏的拉伸与回弹
- **拉伸**：用重复动作、平缓语速、静态画面建立预期
- **回弹**：在毫无预警处迅速打破平衡，用极短的视听语言制造节奏断裂

### 结局
结局应展示弧光完成后的"新常态"——角色变化后的世界是什么样的。不需要解释角色学到了什么，用一个画面让观众自己感受。
