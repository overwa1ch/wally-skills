# 摄影问题排查

用户提出具体摄影问题或已有回片出现偏差时，只读与当前症状有关的行。观察依据可以是用户反馈或获准检查的视频；证据不覆盖的部分保留未核验状态。表内调整是有条件的尝试，不代表已证明能解决某模型的问题。

先核对原设计及实际参考绑定。设计本来没有要求某种效果时，不将其缺席判为错误；设计明确但生成偏离时，区分重试、定向补强和改变设计。修改只涉及造成当前问题的要求，保留未受影响的表演、镜头、声音与连续性。

| 观察到的症状 | 先核对 | 可尝试的定向调整 |
| --- | --- | --- |
| 希望突出主体，却全画面清楚 | 哪个主体应清楚；前中后景关系；实际绑定是否带有不同的清晰范围 | 点名对焦对象、说明摄影机离它很近、光圈全开，并写明哪一层虚掉，见[光学与变形镜头](optics-anamorphic.md)。先保留已确认的机位、主体尺度与构图。 |
| 已选变形镜头外观，当前需要的特征不明显 | 原设计希望看见哪一种特征；画面是否有适合显示该特征的高光或边缘 | 只指定本镜需要的椭圆光斑、边缘特征或其他可见结果，并写清落在哪个对象或区域。已排除眩光时保留该决定，不为显示风格添加亮灯或眩光。 |
| 光斑是圆的 | 原设计是否要求变形镜头观感；画面中是否有可形成光斑的光源 | 写明“竖向椭圆光斑”，并点名它们落在哪些灯光或反光上。 |
| 暖光源上出现蓝色光条 | 光条是否为设计所需；光源颜色 | 把光条颜色改为与光源一致的暖橙色；设计不需要光条时，把眩光排除写进 NEGATIVE。 |
| 面部或近处物体出现不需要的拉伸，或画面出现鱼眼、桶形畸变 | 原稿是否同时要求夸张透视与自然比例；主体距离、画面位置、视角和参考用途是否明确 | 澄清需要保持的比例与当前取景，写明直线不弯曲的画面特征。只有原摄影决定允许改变时才提出调整机位、距离或视角；与已确认决定冲突时单独说明。 |
| 反打后空间、视线或位置不连续 | 分镜给出的机位是否写进对应 SHOT；地点空间是否写明；场景参考是否被当成了机位依据；同一地点及对应视角素材是否绑对；人物站坐高度、朝向和视线目标是否一致 | 先补回分镜给出的机位与地点空间；仍不连续时补足当前镜头的必要空间关系，明确谁看向何处及适用镜号，保留已定运动与构图。底图缺失或空间身份不相容时指出资产问题。 |
| 画面偏亮、偏暗或出现不需要的整体色染 | 参考是否承担光照；总体 LIGHT 与时间段是否冲突；风格是否要求该影调 | 写明有依据的光源、受光区域和需要保留细节的层次。已选光照不变时不重做全场；静态底图重布光交给资产技能的定向修订。 |
| 画面出现品牌标志或文字 | 提示词或参考中是否写了品牌、型号或厂商名称；NEGATIVE 是否包含禁字要求 | 删去品牌与型号名称，改写为外观描述；保留已确认的场内文字。 |

焦距、视角、画幅、景深与光学外观须与当前项目条件相容，不固定换算成一组跨模型数值；三分之四机位、浅景深、手持、胶片颗粒与眩光均按当前设计选择。以新增技术词或长负面清单替代明确画面要求，不能证明问题已经解决。

需修稿时遵循[交付约定](contract.md)，回片判断遵循[回片审查](review.md)；文件校验、生成完成与用户看片接受分别记录。
