# Preview 候选提示词模板

用于 [Preview 方向测试](../references/preview.md)。按 SKILL 的最低数量为每个不同风格方向分别填一份，生成前保存完整提示词，按 [浏览器流程](../references/browser-execution.md) 依次执行。

以下记录字段不发送为生图正文：

```text
版本号：
方向名：
剧本调性依据：
视觉风格依据：所选方向的来源、关键可见定义及其剧本适配性。
参照作品与剧本适配分析：
风格参考图、来源与引用用途：
实际参考接入方式与平台设置：
辅助风格名称或摄影参数及核查来源（需要时）：
共同不变的人物、场景、动作与取景：
完整提示词文件：
```

每版独立填写以下两段正文并绑定所需参考；不用“同上”或依赖上一版本。同轮各版原文复用图片类型、文化信息与构图描述，更换按剧本选择的风格参考及必要的辅助文字。正文相同时，参考绑定仍须逐版完整记录。信息归属与可见性规则以 [craft.md](../references/craft.md) 为准。

```text
整体风格：[图片类型定义。][自然写出的地域、时代与相关物质文化。][视觉风格的关键具体定义，直接说明模型应生成的画面特征；风格名称或有出处的摄影参数按需辅助。]

构图描述：单幅[画幅]效果图，[可见主体与自然姿态]，[环境、位置、空间层次与遮挡关系]，[取景范围、观察角度、需要看清的对象及有依据的局部照明关系。]
```

替换全部占位符。用户指定真实剧照时，第一句为“一张真实电影剧照”。保持文字精简，正文必须保留风格的关键可见定义，不只写名称或感受；不写“文化锚点为”、片名风格、参照选型分析、核查来源或执行说明。

视觉风格的依据与实现由 [style-aesthetic.md](../references/style-aesthetic.md) 规定。参考选择、关键定义、必要参数和回图检查由 Agent 处理；给用户看具体写法及实际效果，不要求用户填写摄影或美术指标。
