# Preview 候选提示词模板

用于 [Preview 方向测试](../references/preview.md)。按 SKILL 的最低数量为每个不同风格方向分别填一份，生成前保存完整提示词，按 [浏览器流程](../references/browser-execution.md) 依次执行。

以下记录字段不发送为生图正文：

```text
版本号：
方向名：
剧本调性依据：
本方向与其他候选的可见差异：
共同不变的人物、场景、动作与取景：
完整提示词文件：
```

每版正文仅由“图片类型定义＋文化锚点＋视觉风格参照＋画面描述”依次组成，写成一个自然段，不显示字段名。参照词的可选来源见 [Preview 写法](../references/preview.md#提示词写法)。

```text
生成一张[明确的图片类型]，[故事发生的具体年代与地域]，采用[视觉风格参照名称]的视觉风格，[主体、动作或状态、环境、时刻与必要空间关系]。
```

替换全部占位符并整理标点；不用“同上”或依赖上一版本。有锁定媒介时沿用，无锁定媒介时仍须明确本候选的图片类型。通常只选一个主参照，不附创作年代；明确要求的画幅或构图并入画面描述。只更换参照词即可测试一个新方向，不默认展开相机参数、细碎调色、纹理或暗部细节。
