# Preview 候选提示词模板

用于 [Preview 方向测试](../references/preview.md)。按 SKILL 的最低数量为每个不同风格方向分别填一份，生成前保存完整提示词，按 [浏览器流程](../references/browser-execution.md) 依次执行。

以下记录字段不发送为生图正文：

```text
版本号：
方向名：
剧本调性依据：
本方向与其他候选的可见差异：
共同不变的人物、场景、动作与取景：
完整提示词文件：
```

每版独立填写以下正文并提交，写成一个自然段，不分字段。开头定义图片类型，必写具体年代与地域；风格遵循 [Preview 写法](../references/preview.md#提示词写法)，不追加纹理、暗部等细节。

```text
生成一张[明确的图片类型]，画面是[具体年代]的[具体地域]，[共同底稿中的人物、场景与自然动作]，采用[本方向的明确调色或已有定义的艺术风格]，[仅在必要时补充的画幅、空间关系或其他已确认要求]。
```

替换全部占位符，删除不必要的可选部分并整理标点；不用“同上”或依赖上一版本。有锁定媒介时沿用，无锁定媒介时仍须明确本候选的图片类型。图片类型和风格名称已传递的信息不重复展开。
