# Preview 全局视觉方向测试

Preview 决定后续资产共同继承的视觉效果。候选数量以 [SKILL.md](../SKILL.md) 的“候选版本与选择”为准；每套提示词探索一个有实质差异、符合剧本整体调性的方向。

## 先确定共同依据

- 读取当前剧本或用户提供的故事材料、作品定义、参考图和明确视觉约束。提取整体情绪、类型、叙事态度、人物处境、地域、时代及真实感要求，写成简短的共同调性依据。
- 保留用户已限定的媒介、年代、身份和世界事实。媒介尚未锁定时可探索不同媒介；已限定实拍、二维或其他形式时，在该形式内部探索不同方向。
- 确认当前资产范围和 `regional_anchor`；已有明确决策不重复询问。不要求先锁定唯一 `style_aesthetic` 才能进行 Preview。
- 没有完整剧本也可使用当前材料中的明确调性；只有调性缺失或冲突到会实质改变候选方向时，询问具体缺失项，不自行编写故事或决定调性。

## 提示词写法

正文仅按以下四部分依次组成一个简短自然段：**图片类型定义＋文化锚点＋视觉风格参照＋画面描述**。

1. **图片类型定义**：先说明这是什么图，如电影剧照、电视剧截帧、角色定妆照、杂志摄影或插画。使用已有明确含义的名称，不能只写“Preview”“效果图”或“视觉候选”。
2. **文化锚点**：写明故事发生的具体年代与地域，只在必要时补充社会环境；不能只写“当代”“复古”“东方”等泛称。沿用材料中的事实；探索尚未锁定的年代或地域时，在候选记录中标明这是方案，不能回写为剧本事实。
3. **视觉风格参照**：用已有名称作为风格锚点，唤起整体视觉联想；可选来源见下表。通常一个主参照即可，必要时增加一个相容的辅助参照，不要求遍历或叠加全部类别。
4. **画面描述**：只写主体、动作或状态、环境、时刻与必要的空间关系；明确要求的画幅和构图也放在这里。

### 视觉风格参照的来源

| 类别 | 可用名称示例 |
| --- | --- |
| 创作者风格 | 王家卫、韦斯·安德森、周星驰、宫崎骏 |
| 具体作品 | 《花样年华》《布达佩斯大饭店》《功夫》 |
| 影视传统与类型 | 港式无厘头喜剧、日式家庭剧、韩国犯罪电影、黑色电影 |
| 艺术流派与表现传统 | 印象派、表现主义、超现实主义、波普艺术、中国水墨 |
| 摄影与成像风格 | 富士、柯达、宝丽来、黑白胶片，以及具体胶片型号或胶片模拟名称 |

- 这些是可选来源，示例不构成必选名单。允许“富士”这样的概括参照词，不强制细化到具体型号；采用用户给定的名称或有明确出处的参照，不自造风格标签。
- 具体年代只用于文化锚点中的故事时间，视觉风格参照不附创作年代；参照作品的故事年代和地点不自动进入本片。
- 让参照词带动整体构图、用光、色彩与人物呈现，不默认把它拆成一组手工参数。相机参数、细碎调色和布光描述不作为默认项；用户明确限定调色测试时，使用其指定的调色术语作为本轮视觉参照。
- 禁止描写纹理、暗部层次及同类微观细节，不堆叠材质、颗粒、瑕疵等修饰，也不把这些禁令塞进生图正文。图片类型、文化锚点与参照词已传递的信息不重复展开。
- 四部分连成一段，不显示字段名，不使用 `Style:`、`Camera:` 等标签或参数表。各套独立完整，不用“同上”；编号和候选记录放在正文之外。

## 设计有比较价值的方向

先为整组候选准备一张内部方向表：版本号、方向名、关键视觉差异、符合剧本调性的依据、保持不变的事实、完整提示词位置。

- 每个方向以一个不同的视觉风格参照为主要变量，保持图片类型、文化锚点与参照相容；不用固定八种风格名单套所有剧本。
- 从适合当前材料的参照来源中选择方向，比较它们对整体视觉的影响；不要求每类都选，也不将整轮默认收窄为配色变化。用户列举的名称用于说明探索范围，除非明确点选，不自动成为必选名单。
- 先逐项检查候选是否背离剧本情绪、人物处境、地域或时代；不合适的方向在生成前改掉，不为凑数量加入不相干的风格。
- 使用同一代表性人物、场景、自然动作及必要的取景范围作为比较底稿；这些内容来自当前材料。保留用户锁定的构图，其他构图与用光允许随参照词变化，以观察整体风格影响。
- 每张仍为以人物为主体的单幅效果图，兼顾人物、环境与整体氛围；不生成分镜序列或在一张图里拼装多个风格版本。
- 每套都是包含四部分的独立完整提示词。只替换视觉风格参照词即可构成不同的测试方向，无需另加细节制造差异；实际图像是否形成可见差异在生成后核验。重复相同提示词或仅更换编号不算新方向。
- 若用户已锁定全局风格且只需生产资产，继承该选定结果；只有用户要求重新探索 Preview 时才重新打开方向选择。

## 依次生成与比较

按本页写法与 [Preview 模板](../templates/preview-prompt.md) 写出整组完整提示词，检查四部分及其顺序和单段格式，再按 [browser-execution.md](browser-execution.md) 在本项目专属 Preview 聊天中依次提交。每次只生成一个独立版本，保留共同依据，不继承前一张候选的风格为默认。

每版检查：

- 是否符合剧本整体调性，人物是否属于该世界；
- 是否保留具体年代、地域与社会事实；
- 是否符合声明的图片类型，是否呈现视觉风格参照带来的整体效果；
- 不同候选之间是否存在可见的风格差异；
- 是否有提示词污染、无关框外细节、泛化美化或图像缺陷。

按版本号展示所有候选原图，附方向名、简短差异和必要问题；可另附比较表。提示词与生成证据按浏览器流程归档，默认不把大段提示词当交付主体。

## 用户选择与全局继承

用户选定某一候选后，保存选定版本、原图、提示词和用户选择依据，把实际选定效果归纳为当前 `style_aesthetic`；随后正式资产共同继承该参考与风格规则，不能各自重新发明全局风格。

用户不满意时按反馈开启新的候选轮次，保留旧记录；用户要求融合若干方向时生成新的验证结果并再次让用户选定，不把未经验证的混合效果当成已确认方向。技术评审或批量执行授权都不替代用户选图。选择与归档格式见 [候选生成记录](../templates/generation-record.md)。
