# Cxx 基础角色

一份 `Cxx` 锁定一个稳定的具名或连续性关键身份：脸、骨骼、体型、比例、基准妆造与生活痕迹。起草前读[共用生产提示词契约](../references/contracts.md)。

布局需要图像辅助时，可用[角色布局板](../assets/cxx-layout-board.svg)；提交方式见[浏览器流程](../references/browser-execution.md#平台能力与布局参考)。

## 输出模板（保留字段顺序，不加序号）

**生成对象与风格**：生成[角色名称]的基础角色参考资产，[视觉媒介与核心风格]。
**画面布局（固定·几何契约）**：16:9角色资产页。左侧为精细半身肖像；右侧为同一角色的A-pose全身正面、侧面、背面三视图，人物从头到脚完整入画。
**角色身份与形体**：[年龄区间、身份、体型、身体比例、面部和骨骼特征、稳定气质]。身体比例依据用户材料和已确认的角色设计，不按叙事地位自动美化。
**妆造**：
   - 服装：[款式、层次、廓形、穿着方式、衣料和维护程度]。
   - 发型与发饰：[发长、造型、分缝、蓬松或贴合状态、发饰及固定方式]。
   - 妆面：[底妆质感、眉眼、唇色、修饰程度，以及年龄、职业和生活状态留下的可见特征]。
   - 配饰：[饰品、眼镜、帽子、随身佩戴物及使用痕迹]。
   - 综合色彩：[服装、头发、妆面和配饰之间的主色、辅助色与明暗关系]。
   - 人物状态：[基准状态下的整洁度、精神状态、身体维护程度和生活痕迹]。
**地域与生活痕迹**：[把 regional_anchor 中与角色有关的地域、时代、气候、职业、阶层和生活条件转成角色身上的可见细节]。
**视觉表现**：[把 style_aesthetic 转成角色的造型方式、材质表现、色彩和媒介质感]。
**光影（固定·呈现契约）**：均匀柔和的摄影棚参考光，身体结构与完整妆造清晰可读，无戏剧性光效。
**背景（固定·呈现契约）**：纯净的中性灰色摄影棚背景，无场景、道具、文字或装饰。
**负面提示词**：[按当次真实风险现写，可从下方评审清单选取]。

## 评审清单

- 确认：每个视图同一身份；脸、骨骼、符合已选媒介的肤质或表面表现、发型、体型、基准服装、鞋、配饰与完整双脚可读。
- 标记：身份混杂、场景专属状态、视图裁切、偏离已选风格的肤质或造型处理。
