# Sxx 地点参考（location_reference）

一份 `Sxx location_reference` 锁定一个稳定地点的空间身份，用一个可复用的宽幅建立视角呈现。起草前读[共用生产提示词契约](../references/contracts.md)。

## 输出模板（保留字段顺序，不加序号）

**地点设计**：生成[地点名称]的地点参考图，[视觉媒介与核心风格]。[地点类型、用途、整体尺度、主要空间关系，以及最能建立地点身份的建筑、陈设、材质和准确标识；只保留影响画面与复用的事实]。
**画面要求（固定·几何契约）**：16:9地点参考图，使用单一宽幅建立视角，完整呈现地点尺度和主要空间关系，关键区域无遮挡、不裁切；默认空场景，只有尺度难以判断时加入一个匿名比例人物，无具名角色和剧情动作。
**视觉呈现**：[把 regional_anchor、style_aesthetic、时间、天气、光线和空气状态转成可见的地域、时代、色彩、材质与氛围]。
**负面提示词**：[按当次真实风险现写，可从下方评审清单选取]。

## 评审清单

- 确认：地点身份连贯；尺度与主要空间关系可读；标志性建筑、陈设与材质史清楚；单一宽幅建立视角；除必要匿名比例人物外空场景。
- 标记：泛化概念图、海报式构图、无依据地标、地点重设计、关键区域被遮挡、具名角色、剧情动作。
