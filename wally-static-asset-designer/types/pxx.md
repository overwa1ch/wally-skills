# Pxx 基础道具

一份 `Pxx` 锁定一个复用、标志性或机制关键道具的基准设计与基准状态，不含剧情摆拍或改变态面板。起草前读[共用生产提示词契约](../references/contracts.md)。

布局需要图像辅助时，可用[道具布局板](../assets/pxx-layout-board.svg)；提交方式见[浏览器流程](../references/browser-execution.md#平台能力与布局参考)。

## 输出模板（保留字段顺序，不加序号）

**生成对象与风格**：生成[道具名称]的基础道具参考资产，[视觉媒介与核心风格]。
**画面布局（固定·几何契约）**：16:9道具资产页。左侧为道具的精细3/4特写；右侧为同一道具的正面、侧面、背面三视图。所有视图完整呈现道具，尺度、结构、材质、颜色、标记和表面状态一致。
**道具用途**：[功能、使用者、出现方式、复用范围和剧情重要性，不展开象征解释]。
**形状与尺度**：[整体轮廓、长宽高、体积、重量感、各部分比例和人手或使用环境中的尺度关系]。
**结构与机制**：[组成部件、连接方式、接缝、活动结构、开合逻辑、抓握点、接触面和实际使用机制]。
**材质与工艺**：[主要与次要材质、制造方式、表面处理、边缘、连接件和物理质感]。
**颜色与基准状态**：[主色、辅助色、明暗关系、基准使用状态、磨损、污渍、氧化、褪色和其他表面历史]。
**标记与文字**：[只在道具确有需要时填写准确的文字、符号、图案、标签及其位置；没有则省略，不生成额外文字或品牌]。
**地域与使用历史**：[把 regional_anchor 中与道具有关的时代、地域、职业、制造条件和使用历史转成结构、材质和磨损]。
**视觉表现**：[把 style_aesthetic 转成道具的造型方式、材质表现、色彩和媒介质感，同时保持结构与机制清楚可读]。
**光影（固定·呈现契约）**：均匀柔和的摄影棚参考光，道具轮廓、结构、材质、接缝、磨损、标记和使用机制清晰可读，无广告化高光或戏剧性光效。
**背景（固定·呈现契约）**：纯净的中性灰色摄影棚背景，无具体场景、人物、文字说明或装饰。
**负面提示词**：[按当次真实风险现写，可从下方评审清单选取]。

## 评审清单

- 确认：一个基准设计与状态贯穿3/4特写与三视图；形状、尺度、构造、材质、抓握点、机制、准确标记、磨损与使用史稳定一致。
- 标记：道具状态混杂、视图不一致、机制不可操作、臆造文字或商标、广告化打磨、出现人物或环境摆设。
