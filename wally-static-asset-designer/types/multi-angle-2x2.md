# Multi-angle 2x2 四宫格场景参考

仅在对应 `Sxx location_reference` 已由用户选定后使用。用户可以直接点名本产物；返回九宫格无法保持场景身份、拓扑、家具、设备、光线或风格时，可建议四宫格，用户选择后再执行。候选数量遵循 [SKILL.md](../SKILL.md)，变化与继承边界见 [contracts.md](../references/contracts.md) 的“正式资产的候选设计”。

按 [browser-execution.md](../references/browser-execution.md) 在当前网页项目内为本地点的2x2 四宫格单独新建并命名聊天，上传已选地点原图与全局风格参考，依次生成本产物的候选版本。

## 固定基础句（逐字，仅替换 XX）

```text
参考场景资产图，生成这个XX场景不同角度不同景别的2×2四宫格场景图。
```

只把基础句的 `XX` 替换为当前场景自然名称，保留其余文字。每套完整提示词由该基础句加上独立的“本版覆盖重点”组成；补充段用于形成不同的角度与景别覆盖方案，不能改变格数、地点身份、拓扑、建筑、陈设、光线或全局风格。

## 每版补充段

```text
本版覆盖重点：[根据已选地点图中可确认的空间关系，写明本版本的观察角度、景别组合与覆盖差异；每格角度有用且不重复]。
保持参考图中的地点身份、空间结构、陈设、材质、光线与已选全局风格。本次只生成这一套独立场景参考图，不与其他候选版本拼成一张图。
```

每版使用不同且完整的覆盖方案，基础句与补充段一次提交；不通过重画同一句或单纯换编号充数。当前类型不套用常规生产资产字段及几何/呈现固定块。文本模式交付各版本完整提示词；版本标签留在正文之外，不附无关分析。

## 评审清单

- 确认：2×2 四宫格成立；四格角度与景别有意义地互不相同；每格保持已确认场景的身份、空间拓扑、建筑、家具、设备、材质、光线与风格。
- 逐版检查基础参考和全局风格继承，跨版本比较覆盖重点的真实差异。
- 标记：格数错误、重复覆盖、地点重设计、空间矛盾、陈设或材质漂移、光线或风格漂移、无关剧情摆拍。
- 展示完整候选包，由用户选择；不自动把第一版、最后一版或技术判定最好的一版当成批准结果。
