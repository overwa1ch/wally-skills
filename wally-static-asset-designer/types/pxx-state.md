# Pxx-state 道具状态

一份 `Pxx-state` 以一个已批准基础 `Pxx` 为身份与结构基准，只锁定一个剧情关键改变态。生产提示词必须附基础 `Pxx` 参考图；缺图时指出缺失并停止，只有用户明确要求草案时才可标注身份锁未决后起草。起草前读[共用生产提示词契约](../references/contracts.md)。

每个目标状态单独制作一张主视图，优先沿用基础参考图的观察方向与构图，使状态变化便于比较；状态改变占用空间时按需调整取景，保留完整的当前形态。

布局需要图像辅助时，可复用[道具布局板](../assets/pxx-layout-board.svg)；提交方式见[浏览器流程](../references/browser-execution.md#平台能力与布局参考)。

## 输出模板（保留字段顺序，不加序号）

**生成对象与风格**：以[道具自然名称的基础参考图]为基准，生成该道具处于[目标状态名称]的道具状态参考资产，[图片类型]。
**画面布局**：16:9道具状态参考图。单一主视图，采用[与基础参考图对应的观察方向、构图与展示尺度]，完整呈现道具的当前形态与可见状态变化。画面只呈现一个目标状态。
**基础道具参考**：以[对应基础道具参考图]作为道具身份、轮廓、尺度、结构、机制、材质、颜色、标记、磨损和基准状态的来源。
**目标状态**：[一个明确的损坏、浸湿、耗尽、开启、激活或其他剧情关键状态；写明可见阶段、程度和范围，原因只在用户材料支持时填写]。
**状态变化**：[相对基础参考图写明发生变化的部件、准确位置、方向、范围、程度和当前结果，只写当前视图可见的变化]。
**保持不变**：[只列会影响身份连续性或机制正确性的少量不变量，例如整体轮廓、尺度、未受影响的结构、关键连接、原有材质、颜色或准确标记]。
**材质与物理表现**：[写明目标状态造成的变形、断裂、湿度、残留、耗损、开合、发光或其他可见物理响应，保持材料行为与结构机制可信]。
**标记与文字**：[只在目标状态改变、遮挡或威胁准确文字、符号、图案或标签时填写；其余由基础参考图承载，不生成额外文字或品牌]。
**地域与视觉表现**：[保留当前道具状态的文化锚点；有风格参考图时直接引用图片，无图时才写视觉风格描述；保留基础身份、结构、机制与状态差异]。
**光影**：均匀柔和的摄影棚参考光，道具轮廓、结构、目标状态、材质变化、接缝、标记和使用机制清晰可读，无广告化高光或戏剧性光效。
**背景**：纯净的中性灰色摄影棚背景，无具体场景、人物、文字说明或装饰。
**负面提示词**：[按当次真实风险现写，可从下方要点选取]。

## 设计与人工审查要点

- 确认：基础 Pxx 身份及未受状态影响的结构、尺度、机制、材质和准确标记保持连续；单一主视图只呈现一个目标状态；观察方向与构图便于同基础图比较；变化位置、程度和物理表现清楚可读，当前形态完整入画。
- 标记：缺少基础参考、道具重设计、多视图或特写拼版、多种改变态混排、基准状态或前后对比面板、损伤位置漂移、无依据的额外破坏、材料响应失真、机制不可操作、臆造文字或品牌、人物或完整场景摆拍。
