# 纪实摄影 Preview 示例

本例展示整体风格与构图描述的两段写法。提示词已获用户认可，图像效果仍须生成验证；示例人物、地点和装备不自动成为其他项目设定。

选型依据：军事行动发生在普通办公空间，人物与危险近距离相处，采用纪实摄影方向检验现场质感。自然光、现场光源与颗粒的研究依据见 [Barry Ackroyd 摄影访谈](https://filmmakermagazine.com/4677-cinematographer-barry-ackroyd-talks-the-hurt-locker-by-scott-macaulay/)。以下为结合本例内容的创作转译，未声称复刻具体镜头或摄影参数。

```text
一张真实电影剧照。2015年，也门亚丁的普通工程项目办公室，同期中国军用服装与装备。纪实摄影风格：保留自然肤色和物体本来的颜色，照明遵循窗户与室内灯具的位置，人物脸部随站位自然落入明暗，室内深处保留较暗的区域。皮肤可见汗水与灰尘，军服有真实褶皱，装备与家具保留使用磨损。画面带适量胶片颗粒，人物与环境具有粗粝、未经美化的现场质感。

16:9横幅，平视三分之二侧面，取景从头盔到大腿。一名约三十岁、面部清瘦、无胡须的中国男性位于画面左半部，穿07式迷彩作训服与国产防弹携行背心，戴头盔、透明护目镜和通信耳塞。双手持黑色QBZ-95-1无托步枪，枪托抵肩，身体贴近厚墙转角，目光与枪口朝向画面右侧资料室的敞开门口。前景墙角遮住少量身体，中景可见低矮布面工位隔板，后景是普通办公桌、旧电脑和未开灯的资料室。侧面窗户装有歪斜的百叶帘，午后光从缝隙照入。右侧留出人物观察的空间，门口与通道关系清楚。单幅画面，无文字、边框或拼图。
```
