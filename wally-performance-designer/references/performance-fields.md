# 表演交付

## 交付范围

人物表演交付以下内容，供摄影与成像组装最终视频提示词：

1. 提示词版本的 `ACTING TASKS`（标准档、完整档）。
2. 逐拍表演：挂在台词或事件上的节拍，不写秒数。
3. `SPOKEN LINE`：说话人、台词原文、声音身份与说话方式，写法见[SPOKEN LINE 与声音身份](spoken-line.md)。
4. 人物起止状态：进入本场时的位置、朝向、持物与处境，以及结尾时的状态。

简单档只交付完整的动作或表情描写。用户只要求修订已有提示词中的表演时，直接修改其中的 ACTING TASKS、SPOKEN LINE 及 THE SHOT 时间段里的表演内容，保留镜头、时间、摄影、灯光和声音设计；需要改变镜头或时长时指出冲突，交回摄影与成像。

## 两层输出

完整档先交付设计说明，用户确认后再写提示词版本。标准档直接交付提示词版本；动机有多种可能且会改变表演色彩时，先请用户选择。

设计说明给用户阅读，可以写完整的推理：

```text
设计说明
事件：……
场面规则：……
人物对照：……
@NAME：动机……；目标……；阻碍……；策略……
需要用户选择：……
```

没有需要用户选择的内容时省略最后一行。

提示词版本只保留画面中看得见、听得见的部分。不在画面中的人物、往事和动机留在设计说明里；只有能用画面内对象和当下动作表达时，才写进提示词。

## ACTING TASKS 写法

```text
ACTING TASKS:
SCENE EVENT: 一句话写这场戏中人物之间发生的事件。
SCENE DIRECTION: 一句话写人物默认遵守的场面规则。
@NAME: 对谁做什么、目光在确认什么、得到什么反馈就改变做法。
```

- 标签用英文和半角冒号，正文使用用户要求的语言；角色名与 REFERENCE 中的 `@NAME` 一致。没有场面规则时省略 SCENE DIRECTION。
- 每个人物一般写一到两句。动机、目标、阻碍只有在能用画面内对象表达、且对表演有独立作用时才写进这一行。
- ACTING TASKS 只写意图层；逐拍表演只出现在 THE SHOT 的时间段里，不在这里重复。
- 面部与目光控制写进人物的策略或对应时间段，不另设面部字段。

## 逐拍表演写法

交给摄影与成像的逐拍表演按台词或事件排列：

```text
@NAME
— “台词原文”或事件触发 — 对对方做什么，目光在确认什么
— 下一拍 — 继续、加强或改变做法
— 转折或结尾 — 最终行为与留下的状态
```

摄影与成像把每一拍落到具体时间段，可以调整落点，不改变表演含义；时长容纳不下时由摄影报告冲突，不自行删减。

## 示意

以下只说明写法，人物与内容不构成设定。

```text
ACTING TASKS:
SCENE EVENT: 出发前最后一次整理行李，两人都不想让告别变沉重。
SCENE DIRECTION: 照常收拾，谁先露出不舍，这份轻松就碎了。
@MOTHER: 照常叠衣服，趁儿子低头时看他，被看见就立刻回到衣服上。
@SON: 照常核对随身物品，只看母亲的手，不看她的脸。
```
