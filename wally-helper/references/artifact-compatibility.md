# Artifact Compatibility Review

Load only when the user requests a review of how supplied professional products fit together.

## Review the supplied evidence

- Confirm the requested source scenes or scope and which supplied versions the user wants to use.
- Compare shared story facts, character and object identities, space, action order, dialogue, timing, and applicable global style or sound decisions. Check only aspects supported by the supplied materials.
- Check whether existing reference names point to the intended supplied assets. Preserve confirmed names and platform syntax; missing assets or ambiguous references require the owning specialist's attention only when they affect the requested result.
- Accept scene prose, tables, and other specialist formats. An omitted optional field or different layout is not a conflict.
- Preserve the user's approval status. Distinguish a delivered artifact, a visual test, and an approved result.

## Return a useful finding

State whether the supplied products can support the requested next step. For each material conflict, identify the two conflicting passages or assets, explain the practical consequence, and give a copy-ready request for the responsible specialist. Ask for a missing fact only when it changes that decision.

Story or dialogue revisions go to `wally-screenplay-writer`; shot-design revisions go to `wally-storyboard-designer`; reusable-asset revisions go to `wally-static-asset-designer`; performance, sound, video-prompt, and reference-binding revisions go to `wally-action-designer`.

Keep findings separate from the original products. Helper does not reformat or assemble them, rename references, insert fields, or write missing professional content. The specialist's current output contract governs the deliverable.
