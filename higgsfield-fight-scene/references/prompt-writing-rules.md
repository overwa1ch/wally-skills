# 提示词写作规则

本文件在摄影与成像、人物表演、近身打斗入口和资产技能中保持同一内容；规则的来源与实测经验记录在 Helper 的工作流指南。

模型会尽量把提示词里出现的每个名词画进画面，也会把互相冲突的要求折中成平庸的结果。写入提示词前按以下四条检查：

1. 写画面中可见的结果，不写不该出现的物件或原因。自拍写“自拍角度，手臂伸向镜头”，不写“拿着手机自拍”。
2. 只写当前景别和视图能看到的内容。特写不写裤子、鞋子等全身细节；远景不写眼神细节。
3. 同一属性只给一个方向。“既恐怖又温暖”会得到两者都不成立的画面；确实需要反差时，把两种性质分别放到具体可见的载体上，例如冷蓝的走廊里，她把外套披到他肩上。
4. 动作、姿态和行为的排除写成正面状态，例如“每一脚都低于腰带高度”，不写“不要高踢”；物件、画面瑕疵和成像外观的排除可以写成否定，放在负面字段中。

不在画面中的人物、往事和动机只写进给用户的说明，不写进提示词。内容不确定时写得更少。
