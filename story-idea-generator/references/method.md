# 故事灵感构思方法

方法来源是用户在本项目提供的查理编剧课笔记。本技能由本项目整理，课程方法的引用范围限于这些笔记。

## 用三要素、八属性构思

下表用于内部构思与检查。通常把它们写进自然的故事描述，不逐条输出八格表。

| 要素 | 属性 | 构思要求 |
| --- | --- | --- |
| 人物 | 身份 | 明确事件中的角色和观众跟随的视角。可给身份加入可信的负价值定语，尤其考虑职业正面印象的反面；缺陷必须影响行动。 |
| 人物 | 欲望 | 想得到什么，为什么非做不可。优先使用观众容易共情的原始欲望，如求生、爱、保护、复仇、团聚。 |
| 人物 | 行动 | 用及物动词与明确对象表达人物要做的事；按下文的“过激行为”区分第一次惯性应对与第二次跨越障碍的行动。 |
| 事件 | 核心问题 | 形成一个“能不能完成这件事”的悬念。展开时悬念可以转换，但要连续，并尽量增强压力。 |
| 事件 | 障碍 | 同时考虑环境、对手、自身三类阻力。各类阻力要落到人物的行动中；灵感短文优先显露最有戏的部分。 |
| 事件 | 结果 | 结局的具体胜负不作限定：可以邪恶获胜，也可以不了了之。按故事因果收束，避免依靠巧合解决困境。 |
| 主题 | 正价值 | 故事传递的情感立场必须站在正义、正能量一边。明确故事肯定什么，如善良、正义、责任、母爱、救赎，通过人物选择及其遭遇让观众感受到它。 |
| 主题 | 负价值 | 明确什么与正价值对抗，并将其落实为利益、行为或关系中的压力。 |

灵感阶段可以停在有力的困境上，保留结果供后续开发。不要为了展示八属性而提前写完结局、补设定或添加说教。

结果回答“最后发生了什么”，主题的情感立场回答“故事让观众在情感上认同什么”。正义可以在情节中失败，故事仍可让观众为它的失败痛惜、对不义感到愤怒，从而肯定正义的价值。这里的正能量体现在价值认同上，不要求圆满或快乐的结局。

## 激励事件与两次过激行为

按用户补充的课程方法，事件从打破人物日常的“激励事件”（干扰事件）开始，常用两类预设：

- **小人物出大事**：事件超出人物平日能够应付的范围。
- **大人物遇小事**：让人物陷入“龙游浅滩、虎落平阳”的处境，原有优势受到限制。

大人物办大事往往属于其日常。构思时要判断事件对这个人物造成了什么干扰，不能只凭事件规模大就认定它有戏。

人物为应对事件采取的行动，在这套方法中称为“过激行为”：

1. **第一次是惯性动作**：沿着人物已有的思维和做事方式行动，符合观众对人物的预期。通常会失败，不在这一步刻意求新。
2. **第二次才可能跨越障碍**：前一次应对失败后，人物被逼着进一步行动，采取真正能够越过障碍的做法。把行动上的创意放在这里，并让它与前一次行为及其后果形成因果关系。

灵感短文按需要呈现这条行动链，不必为了展示两个步骤而提前展开完整剧情。

需要具体说明两次过激行为如何形成因果时，读取[《录取通知书》案例](accepted-example.md)；普通灵感生成不默认加载案例。

## 熟悉的期待与有效的新意

采用用户提出的尺度：故事八要素有四项创新即可，要满足观众对故事的预期，“一半海水，一半火焰”。

- 用熟悉、清楚的欲望与类型期待帮助观众进入故事，在人物关系、任务、障碍或结果上寻找变化。
- 四项创新是够用的参考量，不要求八项全部求新，也不靠逐项打勾凑数。
- 用户认为环境已经足够新颖、勾人时，沿用这个看点，把创作精力放在人物和事件如何与环境发生关系。
- 人物缺陷要可信。避免离奇定语、标题党身份，以及对故事行动没有影响的反差。
- 新意要产生因果：人物的身份或关系改变了任务的难度、代价或选择，才算有用。
- 创新仍应兑现用户选择的类型看点，把看点落实到可展开的人物行动与对抗中。

## 让每一条都有戏，并让整批有区别

先为每条找到一条简短的因果链：

一个具体的人，为了一个能理解的欲望，采取明确行动；某种阻力或关系使行动变得困难，逼他面对代价或选择。

这条链用于构思，措辞、起笔和悬念位置可以变化。

- 让人物的缺陷、过去的行为或重要关系进入当前事件，使冲突具有这个人物独有的压力。
- 优先使用情境和行动呈现张力。
- 改变职业或名字通常不足以形成新故事。检查一批候选在主角位置、欲望、任务、关系、阻力及选择上是否有实质差异。
- 用户允许广泛发散时，避免全批都是同一种任务与冲突；用户指定同一任务时，在人物关系和代价上拉开差异。
- 当某条必须依靠新增世界规则才能成立时，说明这个新增条件，或换成现有规则下即可成立的构思。
- 不确定的细节少写。此阶段不必补齐人名、地名、年代、组织体系和生理机制。

## 交付前检查

- 故事传递的情感是否站在正义一边？是否把这一要求误写成好人必须赢、邪恶必须受惩罚？
- 用户要求的数量是否满足，已有设定和限制是否保留？
- 每条是否都能看出谁想得到什么、正在做什么，以及什么阻止他？
- 激励事件是否打破了这个人物的日常，人物与事件的大小关系是否产生了具体困境？
- 已展开两次过激行为时，第一次是否符合人物惯性与观众预期，第二次是否承接失败并提供跨越障碍的办法？
- 人物的缺陷或关系是否真的改变事件，而非只有标题反差？
- 一批故事是否有区别，是否兑现类型期待？
- 是否把候选情节误写成已确认事实，或为了新奇添加了不必要的规则？
- 文字是否具体、简短，读完能想象故事继续发生？
