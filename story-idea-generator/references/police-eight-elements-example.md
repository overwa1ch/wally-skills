# 想要殉职的警察：故事八要素案例

来源：B 站「查理老师的编剧课」，[第八课·勾勒画面 8.2（P16）](https://www.bilibili.com/video/BV1eE411F73t/?p=16)与 [8.3（P17）](https://www.bilibili.com/video/BV1eE411F73t/?p=17)。两集现场把此前的八要素故事展开为十个序列。本页依照课堂后半段的复述整理主线，八要素对应关系是分析归纳；课堂提出的其他选择另列。

## 故事经过

一个失职、潦倒的中年协警，在夜市独自喝酒。几个歹徒欺负摆摊的小夫妻，他看见却不管。有人报警，他的对讲机响起，众人才发现他是警察；他关掉对讲机继续喝酒，歹徒也继续行凶。开场用这一连串动作交代他的失职，并留下后续事件的起因。[8.2，05:16 起](https://www.bilibili.com/video/BV1eE411F73t/?p=16&t=316)

妻子已与他分开，妻女身边有了另一对父子。他上门受到冷遇，女儿需要学费，他又拿不出钱。回到单位，同事为一名殉职警察的家属募捐，他由此得知抚恤金的事，产生了一个念头：通过殉职给妻女留下一笔钱。[8.2，10:08—20:45](https://www.bilibili.com/video/BV1eE411F73t/?p=16&t=608)

他开始主动冲进危险，希望在执行任务时死去。但救火、救人等尝试接连失败；一次重大爆炸威胁中，他不顾危险接近歹徒，反而把对方吓得放弃抵抗。他没能殉职，却因表现英勇受到表彰，并在课堂设想中由协警转为正式警察。身份和他人态度的变化让他短暂得意，求死的计划也暂时搁下。[8.2，20:46 起](https://www.bilibili.com/video/BV1eE411F73t/?p=16&t=1246)；[8.3，21:01—24:00 的复述](https://www.bilibili.com/video/BV1eE411F73t/?p=17&t=1261)

他再次去找妻女，仍没有得到接纳；学费的期限已过，表彰也没有解决眼前的问题。更大的打击随之而来：开场被他放过的歹徒再次作案，杀了人。先前的失职造成严重后果，他无法原谅自己，也意识到荣誉并没有让自己成为称职的警察或父亲。他决定查找这些歹徒，弥补自己造成的过失；在调查、跟踪和冲突中，又因能力不足受挫，最终打算与歹徒同归于尽。[8.3，00:00—08:42](https://www.bilibili.com/video/BV1eE411F73t/?p=17)

高潮是他与歹徒的拼死搏斗。课堂暂用的结尾是：他重伤后在医院醒来，发现女儿正向别人炫耀父亲的英勇。他舍不得打断，继续闭眼装昏迷，嘴角露出笑容。妻子没有回来，女儿重新认可了他。[8.3，14:15—15:25](https://www.bilibili.com/video/BV1eE411F73t/?p=17&t=855)；[29:10—29:48 的结尾复述](https://www.bilibili.com/video/BV1eE411F73t/?p=17&t=1750)

## 对应八要素

沿用技能中「人物、事件、主题」三个要素、八个属性的分组。下表同时写出故事起点与发展中的变化。

| 要素 | 属性 | 这个故事中的具体内容 |
| --- | --- | --- |
| 人物 | 身份 | 失职、缺钱、与妻女疏离的中年协警；因冒险立功成为受表彰的正式警察；随后必须用自己的行动承担警察与父亲的责任。 |
| 人物 | 欲望 | 起初想通过殉职给妻女留钱，补偿家人；获得荣誉后一度期待重新得到妻女认可；旧日失职的后果迫使他进一步追求弥补过错、成为真正有担当的人。 |
| 人物 | 行动 | 主动投入危险任务求死，多次尝试却意外立功；得知自己放过的歹徒杀人后，调查、跟踪并与他们决战。前后的冒险看似相近，动机已加入对具体过失的承担。 |
| 事件 | 核心问题 | 开始是他能否殉职、留下钱；表彰带来短暂希望后，悬念转向他能否弥补失职造成的后果，以及这次冒险能否活下来。 |
| 事件 | 阻力 | 求死阶段，他的冒险意外化解危险，使求死失败；荣誉又没有换来妻女接纳。弥补过错阶段，凶恶的对手、自己的能力不足以及死亡危险构成直接阻力。 |
| 事件 | 结果 | 按课堂暂用的医院结尾，他经历决战、重伤幸存，重新得到女儿的认可；妻子没有回来，家庭关系只修复了一部分。 |
| 主题 | 正价值 | 担当、尽责、弥补过错，以及由行动赢得的亲情与认可。具体落点是：他主动追查因自己失职而放过的歹徒，女儿最终以父亲为荣。 |
| 主题 | 负价值 | 失职、逃避与虚假的自我满足。开场见人受欺负而不管，后来一度把荣誉当成改变处境的答案，但受害者的遭遇使他无法继续逃避。 |

老师在讲解中反复用生死、真假组织冲突；正负价值栏是依据人物行为作出的归纳。角色前期想死，观众后来却盼他活下来；外部表彰先改变他的身份，弥补过错的行动才使这份身份获得分量。讲解依据见 [8.3，05:50—08:42](https://www.bilibili.com/video/BV1eE411F73t/?p=17&t=350)与 [26:09—27:59](https://www.bilibili.com/video/BV1eE411F73t/?p=17&t=1569)。

这个案例适合说明八要素之间的联系：**失职行为留下后果，家庭和钱的压力促成求死，求死的尝试带来虚假胜利，旧日过失又击碎胜利，逼出新的行动。** 老师在 [8.3，30:11—30:53](https://www.bilibili.com/video/BV1eE411F73t/?p=17&t=1811)强调，身份、欲望、行动、问题、阻力和正负价值应在序列中变化。使用本案例解释八要素即可；只有进入万字纲阶段时，才继续展开十序列。

## 课堂中的备选与调整

- **事件次序经过调整。** 8.2 先想到大型爆炸威胁，后来把它放到多次求死失败之后，再接表彰和身份变化；主线按调整后的顺序整理。
- **再次作案的具体后果有多个提案。** 老师比较了不同伤害程度，复述时倾向采用杀人，因为与生死主题相连。主线采用这一选择，不将受害者固定为女儿，也不把其他提案累加进去。[8.3，24:31—26:34](https://www.bilibili.com/video/BV1eE411F73t/?p=17&t=1471)
- **结局没有唯一指定。** 老师先提出牺牲后举行追悼会，又提出医院苏醒、家人回归等选择，最后暂用「妻子不回来，女儿认可他」的医院结尾。使用牺牲结局时，结果栏应相应改写；担当的价值仍可成立。[8.3，12:09—15:25](https://www.bilibili.com/video/BV1eE411F73t/?p=17&t=729)

案例中的抚恤金和身份晋升服务于课堂构思，不作为现实警务制度依据。
