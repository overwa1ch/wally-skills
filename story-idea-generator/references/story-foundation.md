# 故事基础：三要素、八属性

方法来源是用户提供的查理编剧课笔记，引用范围限于这些笔记。

## 用三要素、八属性构思

下表提供人物、事件与主题的共同基础。只按当前阶段的方法运用，不因读取共同基础而加载另一阶段材料。

| 要素 | 属性 | 构思要求 |
| --- | --- | --- |
| 人物 | 身份 | 明确事件中的角色和观众跟随的视角。可给身份加入可信的负价值定语，尤其考虑职业正面印象的反面；缺陷必须影响行动。 |
| 人物 | 欲望 | 想得到什么，为什么非做不可。优先使用观众容易共情的原始欲望，如求生、爱、保护、复仇、团聚。 |
| 人物 | 行动 | 用及物动词与明确对象表达人物要做的事；按下文的“过激行为”区分第一次惯性应对与第二次跨越障碍的行动。 |
| 事件 | 核心问题 | 形成一个“能不能完成这件事”的悬念。展开时悬念可以转换，但要连续，并尽量增强压力。 |
| 事件 | 障碍 | 同时考虑环境、对手、自身三类阻力。各类阻力要落到人物的行动中；灵感短文优先显露最有戏的部分。 |
| 事件 | 结果 | 结局的具体胜负不作限定：可以邪恶获胜，也可以不了了之。按故事因果收束，避免依靠巧合解决困境。 |
| 主题 | 正价值 | 故事传递的情感立场必须站在正义、正能量一边。明确故事肯定什么，如善良、正义、责任、母爱、救赎，通过人物选择及其遭遇让观众感受到它。 |
| 主题 | 负价值 | 明确什么与正价值对抗，并将其落实为利益、行为或关系中的压力。 |

灵感阶段可以停在有力的困境上，保留结果供后续开发。不要为了展示八属性而提前写完结局、补设定或添加说教。

结果回答“最后发生了什么”，主题的情感立场回答“故事让观众在情感上认同什么”。正义可以在情节中失败，故事仍可让观众为它的失败痛惜、对不义感到愤怒，从而肯定正义的价值。这里的正能量体现在价值认同上，不要求圆满或快乐的结局。

## 激励事件与两次过激行为

按用户补充的课程方法，激励事件（干扰事件）打破人物日常，常用两类预设：

- **小人物出大事**：事件超出人物平日能够应付的范围。
- **大人物遇小事**：让人物陷入“龙游浅滩、虎落平阳”的处境，原有优势受到限制。

大人物办大事往往属于其日常。构思时要判断事件对这个人物造成了什么干扰，不能只凭事件规模大就认定它有戏。

人物为应对事件采取的行动，在这套方法中称为“过激行为”：

1. **第一次是惯性动作**：沿着人物已有的思维和做事方式行动，符合观众对人物的预期。通常会失败，不在这一步刻意求新。
2. **第二次才可能跨越障碍**：前一次应对失败后，人物被逼着进一步行动，采取真正能够越过障碍的做法。把行动上的创意放在这里，并让它与前一次行为及其后果形成因果关系。

灵感短文按需要呈现这条行动链，不必为了展示两个步骤而提前展开完整剧情。

需要具体说明两次过激行为如何形成因果时，读取[《录取通知书》案例](accepted-example.md)；普通灵感生成不默认加载案例。
