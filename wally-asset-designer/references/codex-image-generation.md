# Codex 内置生图与资产归档

图片生成、编辑或恢复时读取本文件与[生成记录](../templates/generation-record.md)。使用当前 Codex 提供的内置生图工具（`image_gen`），按工具的实时说明提交与等待结果。工具不可用时说明缺失能力并保留已准备的输入，不自动切换网页端、账号或其他服务。

## 输入与参考绑定

- 每项保存资产键、轮次、版本、完整提示词与实际参考用途。沿用定稿正文，每次工具调用明确对应一项输入；只生成用户要求的数量。角色页是一张完整图片，保持对应类型的版式合同。
- 新建无参考图片时省略图片引用参数。全部参考均有本地路径时使用 `referenced_image_paths`；需要引用没有本地路径的会话图片时，按工具说明使用覆盖目标图片的最小 `num_last_images_to_include`。两种方式不同时提供；无法包含全部必需参考时指出缺失。
- 编辑时明确唯一目标图、本次变化与保留内容。按内置工具要求读取尚未看过的编辑输入，用于确认绑定和修改范围；不据此自行扩展设计、选定版本或追加修复。
- 透明背景按用户要求设置；编辑时保留已有透明度，除非本次要求改变。只使用工具实际支持的参数；画幅与版式同时写入提示词，实际尺寸以返回文件为准。模型或参数未提供时记“未暴露”。
- 可选布局板需要用作图片参考时转为工具支持的格式，说明仅约束分区和视图位置。必需基础资产必须真实接入；缺失时保留该项输入并说明阻塞原因。

## 提交与收集

1. 核对完整输入与参考路径，调用内置生图工具；保留实际调用参数和工具返回的回执或结果关联。无需创建网页项目或独立聊天。
2. 按当前工具的返回方式等待。工具仍在运行时继续等待原调用；返回任务标识时按其支持的查询方式恢复，不重复提交。同步返回结果的调用直接记录已生成。
3. 保留全部返回原图，并将结果关联到对应输入。读取返回的本地路径或原生结果位置；响应中含图片数据时不把大段编码内容写入日志或用户消息。

执行状态按已观察事实记录：`prepared` 为输入已就绪；`submitted` / `generating` 仅在工具回执支持时使用；原生结果返回记 `generated`；文件已归档记 `archived`。失败记 `failed`，缺少能力或必需输入记 `blocked`。不为同步工具补造中间状态、任务 ID 或完成时间。

## 原图与交付

- 保留工具返回的原始文件；项目需要集中保存时复制原始字节，采用资产键、轮次与版本命名。输入图、历史版本和工具原文件继续保留。
- 核对文件关联、可读取性、格式、尺寸与 SHA-256。记录工具实际返回的模型、参数和时间；完成时间未提供时注明，并另记结果观察时间。尺寸不符时如实交付记录，不自动重绘。
- 使用工具已展示的原生图片或返回的本地文件交付；项目资产可附可点击的原图路径。全部结果交给用户，不自行筛选、评分或追加生成；按[人工审查流程](review-protocol.md)记录 `pending_human_review`。

## 失败与恢复

- 回执不明或中断后，先检查已有工具结果、任务标识与已保存文件；无法确认失败时不重投。
- 工具明确报告生成失败且没有原生结果时，保留失败信息，按相同输入最多重试一次；失败尝试不增加候选版本号。
- 错误提示与可用原生文件同时返回时，一并保存并核对关联，图像内容仍交用户审查。
- 只有复制、保存或展示失败时，恢复已有结果，不重新生图。
- 用户给出修改意见后，只对指定版本提交本次修订，并记录原话、目标版本和新结果。生成、归档、人工审查与明确选定分别记录。
