# 人工视觉审查与反馈处理

在交付候选包、整理人的审查意见或按反馈修改输入时读取。Agent 负责准备、提交、收集和记录；编辑输入按工具要求读取，设计判断与生成结果的视觉审查由人完成。

## Agent 的核对范围

- 提交前检查文字材料、完整提示词与已选参考的绑定关系，保留剧本事实、用户约束和所选类型合同。
- 提交后按 [codex-image-generation.md](codex-image-generation.md) 核对工具返回、任务状态、文件关联、文件可读取性与元数据。
- 说明的是输入的设计意图及文字差异；生成图的实际差异、缺陷和适用性等待人工意见。
- 类型文件中的要点用于设计输入，也可供人审查时参考；不逐张调用视觉工具检查或打分，不填写 Agent 的 `usable` 等视觉判定。

## 整轮交付

- 展示全部候选原图，版本、输入与工具结果一一对应；不按 Agent 偏好删图或排序。使用原生图片或返回的本地文件交付。
- 按本次请求的资产与版本组织结果；缺失项单独列出。
- 人可以直接给出“喜欢这个”“太假”“继续这个方向”等整体反馈，无需填写明暗、色彩或摄影参数评分表。
- 第一轮出图完成后停在人工审查；后续轮次也在完整交付后等待人的反馈。尚未收到反馈时，保持 `pending_human_review`。

## 按人的反馈继续

- 记录审查人、时间、原话和对应版本。保留、放弃、修改及未审状态均以人的明确意见为准。
- 将修改意见转成下一次完整输入，保留用户要求不变的条件；不从“继续探索”推定为“选定采用”。
- 用户指定修某个候选时只处理该候选；用户要求新一轮探索时按明确范围建立新轮次。新的生成输入使用独立工具调用并关联指定目标版本。
- 用户明确选定后保存选定版本及原图位置，依赖资产按已选引用继续。生成完成、文件归档、人工审查和用户选定是分别记录的事实。
